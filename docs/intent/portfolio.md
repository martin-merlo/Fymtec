# Declaración de intención: sitio de marca / estudio de software

> Confirmada el 2026-09-28 tras la entrevista (`interview-me`). **Actualizada el 2026-10-07:** la marca es **Fymtec**, con logo y paleta definidos. Es la fuente de verdad sobre **qué** queremos lograr; el **cómo** vive en [`SPEC.md`](../../SPEC.md).

## Resultado

El sitio de una marca de software independiente que sea, en sí mismo, la demostración de la calidad del trabajo que ofrezco. Tiene que sentirse como un producto cuidado, no como una plantilla de portfolio. Las animaciones y microinteracciones son importantes, pero cada una tiene que estar justificada y no perjudicar la claridad, la performance ni la usabilidad.

## Percepción

Primero se percibe una marca/estudio de software independiente; después el usuario descubre que detrás estoy yo. **Nada** del típico "Hola, soy Martín, estas son mis tecnologías".

## Para quién (en dos capas)

1. **Primera capa, para el potencial cliente no técnico (prioridad):** qué problema puedo resolver, qué hago, qué trabajos realicé y cómo contactarme.
2. **Segunda capa, para quien quiera profundizar (por ejemplo, un líder técnico):** stack, GitHub y decisiones de implementación.

## Servicios

Soluciones digitales para negocios, no solo "hacer páginas web": desarrollo web, aplicaciones y sistemas a medida, SEO y optimización cuando corresponda, y eventualmente automatización e integraciones. El wording exacto se define durante el diseño del sitio.

## Contenido

- Entre 3 y 5 casos fuertes, con **formato variable**: algunos como case study completo, otros como presentación más visual.
- Importa más la calidad de la evidencia que la cantidad. El resto va como proyectos secundarios.
- Cada caso se cuenta con honestidad: contexto o problema → solución → qué hice yo → tecnologías → decisiones de diseño/desarrollo → resultado visual o funcional.
- Material disponible: Roma Barber Club, International Freight Forwarder, Liga Mendocina de Ajedrez, portfolio de Salomón Barrios y la auditoría SEO de La Retama (por ahora solo auditoría).

## Restricciones

- **Stack:** Next.js + Tailwind + shadcn/ui + Framer Motion, con deploy en Vercel.
- **Componentes:** 21st.dev y Uiverse sirven como fuente o inspiración, siempre adaptados a un único sistema visual. La consistencia es prioritaria: no tiene que parecer una colección de componentes de distintas páginas.
- **Performance:** buenos Lighthouse y Core Web Vitals. Progressive enhancement, lazy loading, imágenes optimizadas y respeto por `prefers-reduced-motion`.
- **SEO:** el propio sitio tiene que demostrar buenas prácticas técnicas de SEO.
- **Idioma:** todo en español por ahora, con una arquitectura que permita sumar inglés sin rehacer el sitio.
- **Marca:** **Fymtec**, con logo y paleta definidos (2026-10-07); la tipografía sigue abierta. Todo se sigue trabajando con design tokens y variables, para que cambiar la identidad no implique reconstruir componentes.
